# PLP Data Analytics Assignment 2: Rainfall Advisory

 Project Summary
This project processes and cleans raw weather station readings for five Kenyan counties (Nairobi, Nakuru, Kisumu, Mombasa, and Machakos), performs vectorized rainfall analysis using NumPy, identifies optimal agricultural planting windows, and outputs a summary CSV for NGO extension officers.

 Planting Advisory
* Farmers in bimodal rainfall regions should prepare land ahead of the primary long rains peak in April to maximize soil moisture retention.
* Kisumu and Mombasa exhibit extended high-rainfall periods well-suited for sustained crop growth, requiring proactive field drainage management during peak months.
